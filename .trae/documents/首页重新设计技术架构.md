## 3. 组件设计

### 3.1 ParticleBackground 组件

**功能**: 全屏动态几何粒子背景

**实现方式**:
```jsx
// 生成40个随机几何图形
const particles = Array.from({ length: 40 }, (_, i) => ({
  id: i,
  type: ['circle', 'triangle', 'square', 'cross'][i % 4],
  x: Math.random() * 100,
  y: Math.random() * 100,
  size: 4 + Math.random() * 8,
  duration: 15 + Math.random() * 20,
  delay: Math.random() * 10,
  color: ['#00d4ff', '#a855f7', '#ffffff'][i % 3],
}));
```

**CSS动画**:
```css
@keyframes float-particle {
  0%, 100% {
    transform: translateY(0) rotate(0deg);
    opacity: 0.3;
  }
  50% {
    transform: translateY(-30px) rotate(180deg);
    opacity: 0.8;
  }
}
```

### 3.2 GeometricDecor 组件

**功能**: 角落几何装饰元素

**装饰位置**:
- 左上角：三角形
- 右上角：圆形 + 线条
- 左下角：方块 + 十字
- 右下角：三角形

**样式**:
```css
.decor-triangle {
  width: 0;
  height: 0;
  border-left: 30px solid transparent;
  border-right: 30px solid transparent;
  border-bottom: 50px solid var(--accent-primary);
  opacity: 0.3;
  animation: rotate-slow 20s linear infinite;
}
```

## 5. 动画时间轴实现

### 5.1 Hero入场动画

```jsx
const [visible, setVisible] = useState(false);

useEffect(() => {
  const timers = [
    setTimeout(() => setVisible(true), 100),
  ];
  return () => timers.forEach(clearTimeout);
}, []);

return (
  <div className={`transition-opacity duration-1000 ${visible ? 'opacity-100' : 'opacity-0'}`}>
    {/* 内容 */}
  </div>
);
```

## 7. 性能优化

### 7.1 动画优化
```css
.particle,
.geometric-decor,
.gallery-card {
  will-change: transform, opacity;
  backface-visibility: hidden;
}
```

### 7.2 减少动画偏好
```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 7.3 移动端优化
- 粒子数量减少到25个
- 复杂的装饰元素移除
- 动画时长减少50%

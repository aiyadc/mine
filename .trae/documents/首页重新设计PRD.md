# 个人博客首页重新设计 PRD (创意版)

## 1. 产品愿景

打造一个**数字画廊式的工作室入口**——不是传统的博客首页，而是一个开发者/创作者的沉浸式作品展示空间。设计灵感来源于高端科技产品发布会和交互式作品集，让访客感受到这是一个有品味、有技术深度的数字空间。

### 核心设计哲学

* **创新不浮夸**: 独特的布局和动效，但不哗众取宠

* **沉浸式体验**: 让访客沉浸在视觉体验中，忘记是在浏览网页

* **内容为王**: 设计服务于内容，不是炫技

## 2. 创意布局方案：代码编辑器 + 画廊混合风格

### 2.1 整体概念

模拟一个**全屏的创意工作空间**，元素不是传统的卡片堆叠，而是以一种有节奏、有层次的方式展示：

```
┌────────────────────────────────────────────────────┐
│                                                    │
│     「 记录工作与生活 」
│                                                    │
│   ┌─────────────────────────────────────────────┐ │
│   │                                             │ │
│   │          [Avatar]                          │ │
│   │          Eachan                            │ │
│   │          Developer & Creator                │ │
│   │                                             │ │
│   └─────────────────────────────────────────────┘ │
│                                                    │
│   最新文章 01                                      │
│   ────────────                                     │
│                                                    │
│   [Article 1]        [Article 2]                  │
│      ↓                   ↓                         │
│   [小卡片]           [大卡片]                       │
│                    ┌──────────────────┐          │
│                    │                  │          │
│                    │   [Article 3]    │          │
│                    │                  │          │
│                    └──────────────────┘          │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 2.2 详细布局结构

#### **Hero Section（沉浸式自我介绍）**

* **全屏设计**: Hero区域占据首屏，高度100vh

* **居中内容**: Avatar、名字、简介垂直水平居中

* **背景特效**:

  * 微妙的渐变光晕（角落）

  * 几何图形装饰（三角形、圆形）缓慢漂浮

  * 可选：网格线背景（科技感）

* **文字处理**:

  * 中文标语使用超大字体（clamp函数，5vw-8vw）

  * 英文副标题使用细体字，letter-spacing增大

  * 颜色渐变：白色 → 青色 → 紫色

#### **文章展示区域（不规则画廊布局）**

* **不是传统网格**: 采用**瀑布流 + 错落布局**

* **文章卡片尺寸**:

  * 奇数卡片：大尺寸（跨两行）

  * 偶数卡片：小尺寸（标准）

  * 或者：大-小-小-大的节奏

* **视觉节奏**:

  * 每个卡片之间有微妙的错位

  * 使用负margin或transform创造重叠效果

  * 卡片间距不均匀，增加有机感

* **动画入场**:

  * 卡片从下方渐入

  * 带有轻微的旋转（-2deg到2deg）

  * 交错延迟，创造波浪感

### 2.3 装饰元素设计

#### **几何图形装饰**

* 悬浮的小型几何图形（三角形、圆形、方块）

* 颜色：青色、紫色、白色

* 动画：缓慢旋转 + 漂浮

* 位置：

  * 角落固定装饰

  * 文字附近的点缀

  * 文章卡片周围

#### **线条装饰**

* 文章标题前的序号（如 01. 02. 03.）

* 标题下的渐变装饰线

* 分隔区域的几何线条

#### **光效**

* 角落渐变光晕（青色/紫色）

* 卡片悬停时的边框发光

* 背景微妙的网格线

## 3. 视觉设计系统

### 3.1 色彩方案

```css
--bg-primary: #08080c;           /* 极深黑紫（背景） */
--bg-elevated: #0f0f14;          /* 提升层（卡片背景） */
--accent-primary: #00d4ff;        /* 明亮青色 */
--accent-secondary: #a855f7;     /* 紫色 */
--accent-gradient: linear-gradient(135deg, #00d4ff 0%, #a855f7 100%);
--text-primary: #f4f4f5;         /* 近白色文字 */
--text-muted: #71717a;           /* 柔和灰色 */
--border-subtle: rgba(255, 255, 255, 0.08);
--glow-cyan: 0 0 20px rgba(0, 212, 255, 0.3);
--glow-purple: 0 0 20px rgba(168, 85, 247, 0.3);
```

### 3.2 字体系统

* **中文标语**: Noto Sans SC, font-weight: 700, 超大尺寸

* **英文标题**: Space Grotesk（科技感但优雅）

* **正文**: Inter（高可读性）

* **代码/序号**: JetBrains Mono

### 3.3 间距系统

* Hero区域：全屏，padding: 5vh 5vw

* 文章区域：max-width: 1400px, 居中

* 卡片间距：24px基础，使用随机偏移增加节奏

* 垂直间距：section之间100px

### 3.4 动效哲学

* **入场动画**: 优雅、缓慢、有节奏（600ms-1000ms）

* **悬停反馈**: 即时、微妙（200ms）

* **背景动画**: 持续、缓慢、不干扰（10s-30s循环）

* **避免**: 快速闪烁、突然弹出、过度的弹跳

### 3.5 具体动画设计

#### **Hero入场动画**

```
0ms     - 背景渐显
200ms   - 几何装饰开始漂浮
400ms   - 主标语淡入 + 上移
600ms   - Avatar淡入
800ms   - 副标题淡入
1000ms  - 社交链接依次淡入
```

#### **文章卡片动画**

```
- 初始状态: opacity 0, translateY(40px), rotate(-3deg)
- 最终状态: opacity 1, translateY(0), rotate(0)
- 动画时长: 800ms
- 缓动函数: cubic-bezier(0.22, 1, 0.36, 1)
- 交错延迟: 每张卡片间隔150ms
```

#### **悬停交互**

* **卡片**: scale(1.02), 边框发光, 阴影加深

* **Avatar**: 边框旋转加速, 发光加强

* **社交图标**: 颜色变亮, 轻微放大

## 4. 功能模块

### 4.1 ParticleBackground 增强版

* **不再是圆点**: 使用多种形状

  * 小圆圈（粒子）

  * 小三角形

  * 小方块

  * 小十字线

* **动画**:

  * 随机漂浮方向

  * 随机旋转

  * 随机缩放

  * 透明度呼吸效果

* **数量**: Desktop 40个，Mobile 25个

* **颜色**: 青色、紫色、白色（随机）

### 4.2 HeroSection

* **Avatar**:

  * 尺寸: 120px（桌面）, 80px（移动）

  * 边框: 渐变（cyan → purple）旋转动画

  * 悬停: 边框旋转加速，光晕增强

* **主标语**:

  * 中文，超大字体

  * 渐变色文字

  * 可选：打字机效果（逐字显示）

* **副标题**:

  * 英文或中文

  * 细体字，增大字间距

  * 柔和颜色

* **社交链接**:

  * 图标形式

  * 水平排列

  * 悬停发光

### 4.3 LatestPostsSection

* **标题**:

  * "Latest Posts" 或 "最新文章"

  * 序号前缀（01. / 02.）

  * 下方装饰线（渐变）

* **卡片布局**:

  * 不是规整网格

  * 使用CSS Grid + nth-child选择器创造不规则布局

  * 示例:

    ```css
    .posts-grid {
      display: grid;
      grid-template-columns: repeat(12, 1fr);
      gap: 24px;
    }

    .post-card:nth-child(3n+1) { grid-column: span 5; }
    .post-card:nth-child(3n+2) { grid-column: span 4; }
    .post-card:nth-child(3n+3) { grid-column: span 3; }
    ```

* **卡片样式**:

  * 玻璃拟态背景

  * 顶部渐变边框（悬停时显示）

  * 悬停：整体上移，边框发光

  * 包含：标题、日期、标签

## 5. 响应式策略

### 5.1 Desktop (≥1024px)

* Hero全屏，元素居中

* 文章布局：5-4-3列混合

* 大量装饰元素

### 5.2 Tablet (768px - 1023px)

* Hero稍微收缩

* 文章布局：两列交替

* 装饰元素减少

### 5.3 Mobile (<768px)

* Hero紧凑布局

* 文章单列

* 粒子动画减少

* 装饰元素最小化

* 触摸优化

## 6. 技术实现要点

### 6.1 CSS Grid不规则布局

```css
.posts-container {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 1.5rem;
}

@media (max-width: 1023px) {
  .posts-container {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 767px) {
  .posts-container {
    grid-template-columns: 1fr;
  }
}
```

### 6.2 动画性能优化

* 使用 `transform` 和 `opacity`

* 动画元素添加 `will-change: transform, opacity`

* 使用 `requestAnimationFrame` 控制JS动画

* 移动端减少动画复杂度

### 6.3 可访问性

* `prefers-reduced-motion` 支持

* 颜色对比度符合 WCAG AA

* 键盘可导航

* 语义化HTML

## 7. 独特创意亮点

### 7.1 "时间戳"设计元素

* 文章序号使用时间戳格式：2024.01

* 或使用坐标格式：A1, A2, B1, B2

### 7.2 "连接线"装饰

* 卡片之间有微妙的虚线连接

* 暗示内容之间的关联

### 7.3 "呼吸"动画

* Avatar或主标题有微妙的缩放呼吸效果

* 让人感觉页面是"活的"

### 7.4 "玻璃隧道"效果

* 背景有从中心向外的光线效果

* 增强深度感和沉浸感

## 8. 不包含的内容

* 不使用WebGL或Three.js（保持轻量）

* 不添加视频背景

* 不使用过度花哨的字体

* 不改变博客的核心内容展示逻辑

* 不添加复杂的交互（如下拉刷新、拖拽排序）

## 9. 成功标准

1. **视觉冲击力**: 第一眼就让人印象深刻
2. **独特性**: 与常见的博客首页明显不同
3. **流畅性**: 动画丝滑，无卡顿
4. **可读性**: 内容清晰易读
5. **性能**: 首屏加载<2秒
6. **响应式**: 各设备完美展示
